# 小三數學學習站

依照《小學數學新思維》作業 **3上A / 3上B / 3下A** 的課次編排，共 **30 課、300 題**。

每一課＝教學重點（3 段 + 例題）＋ 10 題互動測驗。

## 功能
- 8 種題型：選擇、多選、計算、填充、判斷、排序、配對、圖形選擇
- 逐題即時批改＋解說；提交後計分、可「重做錯題」
- 進度自動存在瀏覽器（localStorage），目錄顯示每課最佳成績
- 純靜態網站，無需後端；手機優先版面

## 結構
```
index.html          目錄（三冊、30 課、進度）
lesson.html         課堂頁（教學＋測驗）
assets/style.css    樣式
assets/app.js       測驗引擎（無依賴）
data/book-a.js      3上A 第 1–10 課
data/book-b.js      3上B 第 11–20 課
data/book-c.js      3下A 第 1–10 課
```

## 課次
**3上A**：五位數／比較數的大小／乘法(一)(二)(三)／毫米／公里／秒／活動時間／24小時報時制

**3上B**：除法(一)(二)(三)／乘除應用題／平行線／平行四邊形和梯形／製作平行四邊形和梯形／重量的認識／克／公斤

**3下A**：加法和減法／圓括號／加減混合應用題／乘加混合運算／乘減混合運算／四則應用題／三角形(一)(二)／製作三角形／繡曲線

## 備註
題目按課本課次自行編寫，用於練習與鞏固，並非課本原題轉載。
